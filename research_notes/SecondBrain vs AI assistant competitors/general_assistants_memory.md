## Key question 1: Per-assistant profiles. Can any of these serve as a complete second brain today (persistent growing corpus of thousands of documents, precise citations, structured who/when/which-type questions, full export)? Where exactly do they fall short?

### Takeaway
None of the eight assistants is a complete second brain for a technical user in October 2026: corpus limits are small (ChatGPT Projects 5–40 files, Claude Projects bounded by context window then RAG "up to 10x", Perplexity Spaces 50 files on Pro, Gemini Notebook 50–600 sources), retrieval is vector/RAG "best effort" with no structured query layer, memory is a vendor-held summary or topic list that is viewable but (except Claude's experimental export) not exportable in structured form and has no read API, uploaded project files are generally excluded from account exports, and no vendor assistant runs a local model for the chat experience. All of them, however, are increasingly capable MCP clients (Claude, ChatGPT/Codex, Gemini CLI, Le Chat, M365 Copilot admin connectors), which is the integration path that matters for SecondBrain.

### Cited Findings

#### OpenAI ChatGPT

Memory
- The official Memory FAQ describes two controls, "Reference saved memories" and "Reference chat history"; saved memories can be deleted individually, cleared, or turned off; the FAQ says memory "is intended for high-level preferences and details, and should not be relied on to store exact templates or large blocks of verbatim text"; deleting a chat does not delete a memory derived from it; Temporary Chat neither uses nor creates memories; the FAQ states "We're rolling out an improved Memory experience over the next few weeks" — [OpenAI Memory FAQ (not fetched directly; from search extraction)](https://help.openai.com/en/articles/8590148-memory-faq)
- A memory-vendor blog (July 12, 2026) reports that on June 4, 2026 OpenAI relabelled the two-toggle setup as "Legacy memory system"; the current default is a single Memory control with an editable memory summary, rolled out first to Plus/Pro in the US; accounts can revert to legacy saved memories under Settings > Memory; Projects can be set to "project-only" or default memory, sharing a project switches it to project-only permanently, and OpenAI may keep logs of deleted memories for up to 30 days — [MemX blog (vendor, secondhand)](https://memx.app/blog/chatgpt-reference-chat-history-vs-saved-memories/)
- Another third-party post (July 15, 2026, updated Sept 21, 2026) says OpenAI's June "Dreaming" update made memory "something that continuously rewrites itself in the background" (a summary rather than a fixed list), cites an OpenAI page at openai.com/index/chatgpt-memory-dreaming/ (not fetched), and states that the Settings > Data Controls > Export ZIP "does not include saved memories" — [Calmara blog (secondhand)](https://calmara.app/blog/migrate-chatgpt-memory-before-it-rewrites-itself)
- An independent portability test (July 16–17, 2026) of seven memory products found "ChatGPT Memory: Account ZIP covers conversations only. Saved memories have no export." — [Stan Tyan, DEV Community](https://dev.to/stantyan/i-tested-7-ai-memory-products-for-portability-all-7-lock-you-in-31pm)
- OpenAI's export article says the ZIP holds chat history and other account data and does not mention memories either way — [OpenAI export article (not fetched directly)](https://help.openai.com/en/articles/7260999)
- Atlas-era "Tainted Memories": LayerX showed (Oct 27, 2025) a CSRF attack that injects hidden instructions into ChatGPT memory, "persistent across all devices that the account is used on", affecting ChatGPT on any browser; OpenAI said it could not reproduce it and had seen no real-world exploitation — [The Register](https://www.theregister.com/2025/10/27/atlas_vulnerability_memory_injection/)

#### Anthropic Claude

Memory
- Memory launched Sept 11, 2025 for Team/Enterprise and Oct 23, 2025 for Pro/Max; Claude keeps a separate memory per project; a viewable, editable "memory summary"; incognito chat for all users; import from other tools and export "for backup or migration" — [Anthropic: Claude Memory](https://claude.com/blog/memory)
- Current help article: memory is saved as individual topics as you chat; Settings > Memory lists "Topics" with edit/delete; "Pause" keeps memory but stops use; "Reset memory" permanently deletes all memories including project memories; deleting a conversation does not remove entries derived from it; memory is on by default for Free/Pro/Max and off per member on Team/Enterprise until each enables it; sensitive topics (health, race, religion, politics, gender identity) are not stored unless "Include sensitive topics in memory" is enabled; government IDs, criminal history, financial account numbers and immigration status are never saved; memory "follows existing chat data retention policies and is included in data exports"; memory is shared with Cowork only when Cowork runs in the cloud, "Local Cowork sessions don't use memory"; not available to orgs under HIPAA, public-sector or custom retention agreements; owners cannot view members' memories; legacy memory export visible until September 9, 2026 — [Anthropic support: How does Claude's memory work](https://support.claude.com/en/articles/11817273-how-does-claude-s-memory-work)
- Aug 25, 2026: Anthropic merged chat and Cowork memory; topics are added during a chat rather than summarised at the end; memory enabled by default on Free, Pro and Max across web, desktop and mobile — [TechCrunch](https://techcrunch.com/2026/08/25/claude-cowork-finally-remembers-what-you-told-the-app-in-chat/)
- Memory import/export (article dated Sept 2, 2026): import on Free/Pro/Max/Team (web and Desktop) by pasting another assistant's memory dump; "export" means viewing memory in Settings > Capabilities or asking Claude to write memories out verbatim and saving the result locally; described as "experimental and still in active development"; memory "focuses on work-related topics" — [Anthropic support: Import and export your memory](https://support.claude.com/en/articles/12123587-import-and-export-your-memory-from-claude)
- Memory for all users including Free is reported as March 2, 2026 by a third-party guide (unverified against Anthropic) — [Lumichats (secondary)](https://lumichats.com/blog/claude-memory-2026-complete-guide-how-to-use)

Projects
- Projects are available on all plans; Free is limited to five; on paid plans (Pro, Max, Team, Enterprise) Claude "switches to Retrieval Augmented Generation (RAG) as project knowledge nears context limits, which can expand capacity by up to 10x"; sharing is Team/Enterprise only; a new beta version (one conversation running parallel cloud threads) is rolling out starting with Claude Code for select Pro/Max users — [Anthropic support: What are Projects](https://support.claude.com/en/articles/9517075-what-are-projects)
- RAG mode: enabled automatically near the context-window limit; uses a "project knowledge search tool" to retrieve the portions it judges relevant; reversible when knowledge drops below the threshold; works with web search, extended thinking and Research; users cannot manually force RAG; the fetched page says RAG is for paid plans — [Anthropic support: RAG for Projects](https://support.claude.com/en/articles/11473015-retrieval-augmented-generation-rag-for-projects); a search extraction of the same article dated March 16, 2026 said "available for all Claude plans (free, Pro, Max, Team, and Enterprise)" and a third-party August 2026 post reports the newer wording limits it to paid plans — [MemoryLake (secondary)](https://www.memorylake.ai/blogs/claude-project-rag-mode)
- Upload limits: project files 30 MB per file with no file-count limit "but their total content must fit within Claude's context window"; chat uploads 500 MB per file and up to 20 files per chat — [Anthropic support: What kinds of documents can I upload](https://support.claude.com/en/articles/8241126-what-kinds-of-documents-can-i-upload-to-claude-ai)
- Simon Willison's 2024 note that Projects had a 200K-token knowledge limit is pre-RAG and possibly stale — [Simon Willison, June 2024 (possibly stale)](https://simonwillison.net/2024/Jun/25/claude-projects)

Connectors and MCP
- Custom connectors using remote MCP are available on Claude (web), Cowork and Claude Desktop for Free (limited to one custom connector), Pro, Max, Team and Enterprise; auth options are "Sign in now", "Sign in when needed" or "No sign in"; OAuth client choices are "Use Claude's published identity (Recommended)", "Register automatically" or "Use your own OAuth client"; request headers can carry "API keys, bearer tokens, or other fixed credentials"; the server "must be reachable over the public internet from Anthropic's IP ranges" (servers behind VPN/firewall must allowlist Anthropic IPs); local MCP via `claude_desktop_config.json` is "not available in Cowork or claude.ai"; the connection originates from Anthropic's cloud "across every Claude client, including claude.ai, Claude Desktop, Cowork, and the mobile apps"; Research can invoke connector tools without further approval and cannot invoke local MCP tools; connectors aren't verified by Anthropic and may attempt prompt injection — [Anthropic support: Getting started with custom connectors using remote MCP](https://support.claude.com/en/articles/11175166-getting-started-with-custom-connectors-using-remote-mcp)
- Pre-built web connectors are available on Claude, Claude Desktop and Claude Mobile (iOS/Android) for paid plans; mobile can use previously configured remote servers but new ones must be added on web or desktop — [Anthropic support: Pre-built web connectors (from search extraction)](https://support.claude.com/en/articles/11176164-pre-built-web-connectors-using-remote-mcp); [DEV Community guide](https://dev.to/zhizhiarv/how-to-set-up-remote-mcp-on-claude-iosandroid-mobile-apps-3ce3)
- Local MCP on Claude Desktop ships as Desktop Extensions (`.mcpb`) installed from a directory or as custom files; secrets stored in Keychain/Credential Manager/distro keychain on macOS/Windows/Linux; Team/Enterprise owners can allow/block extensions — [Anthropic support: Local MCP servers on Claude Desktop](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop)
- Claude Code MCP: transports HTTP (recommended), SSE (deprecated), stdio, WebSocket (header auth only); `--header "Authorization: Bearer ..."`; OAuth via `/mcp` or `claude mcp login`, with `--client-id`/`--client-secret` for servers lacking Dynamic Client Registration; scopes local/project/user; `${VAR}` expansion in url/headers but credential variables such as `ANTHROPIC_API_KEY` read as empty in remote url/headers; claude.ai connectors reach Claude Code only under a claude.ai subscription login; organisation connector tools can be set to `ask` or `blocked`; default MCP output limit 25,000 tokens — [Claude Code docs: MCP](https://code.claude.com/docs/en/mcp)
- Claude Code memory: CLAUDE.md files (user `~/.claude/CLAUDE.md`, project, local, org-managed) plus "auto memory" ("notes Claude writes itself based on your corrections and preferences", scoped per repository and shared across worktrees, loaded "first 200 lines or 25KB"); AGENTS.md can be read in place of CLAUDE.md; `.claude/rules/` path-scoped rules; external `@path` imports require one-time approval per project; Cowork desktop sessions skip user-scope imports outside the working directory — [Claude Code docs: How Claude remembers your project](https://code.claude.com/docs/en/memory)

### Inferences
- Corpus scale: a technical user with thousands of Markdown notes exceeds every consumer corpus limit found: ChatGPT Projects cap at 25–40 files (even at 512 MB each, the unit is "file", not "note"); Claude Projects are bounded by the context window then RAG "up to 10x" with 30 MB files; Perplexity Pro Spaces hold 50 files; Gemini Notebook tops out at 600 sources on the most expensive Ultra tier. SecondBrain's vault plus rebuildable index has no such cap.
- Retrieval semantics: every vendor describes retrieval as the model choosing "relevant" chunks (Claude's "project knowledge search tool", Perplexity's "extracts the most important parts", Copilot Notebooks "silently selects the files it judges most relevant"). None exposes a filter-then-score query over typed properties, people or dates, which is the gap SecondBrain's SQL-answered who/when/which-type questions target.
- Citation precision: Perplexity cites memories and uploads as sources; Gems can show knowledge-file citations; M365 Copilot "shows its work"; but no vendor page describes a citation that resolves to a document revision and excerpt, and none distinguishes "nothing found" from a degraded index. Vendors do not report index health at all.
- Memory is a vendor-side summary or topic list, not a knowledge store: all three big vendors state memory is for preferences/context (OpenAI: not for "large blocks of verbatim text"; Claude: "focuses on work-related topics"; Gemini: "key details and preferences"). It rewrites itself (ChatGPT "Dreaming", Claude 24-hour synthesis in the legacy design), which is the opposite of an append-only, revisioned record.
- Export completeness: conversations are exportable everywhere; memories are exportable only as text (Claude, Mistral, Grok JSON of chats) or not at all (ChatGPT, Gemini saved info, Copilot); project/Space knowledge files are excluded from Claude member exports and unaddressed by OpenAI and Perplexity. No vendor documents a read API for memories.
- Local/offline: only Apple (on-device models with PCC fallback), Google (Gemini Nano in AICore for app features, not the Gemini chat) and Microsoft (Recall's local OCR/index on Copilot+ PCs) run anything on-device; none lets the user point the assistant at a self-hosted vLLM. SecondBrain's `local_only` transport switch has no vendor analogue.
- Continuity risk is real and recent: Atlas lived ten months (Oct 2025–Aug 2026); Copilot Pro lasted under a year; GPT-4o was pulled from ChatGPT in Feb 2026 and GPT-5.2 four months later; Gemini CLI was withdrawn from free/Google One users in June 2026; NotebookLM was renamed; Google cut Ultra by 60% and OpenAI/Anthropic added $100 tiers. A personal corpus that lives inside any of these products inherits that churn.
- Versus SecondBrain (per assistant): ChatGPT offers the richest consumer connector/agent surface but the weakest memory portability and the most contested plan-gating for custom MCP; it complements SecondBrain only on Business/Enterprise/Edu (or wherever developer mode is enabled) via a publicly reachable remote MCP endpoint. Claude is the most natural MCP client (claude.ai/Desktop/mobile remote connectors with OAuth or header credentials, Desktop `.mcpb` local servers, Claude Code stdio/HTTP with bearer headers, Cowork folder access) and already treats memory as topic entries with export; what it cannot give is a typed, revisioned corpus with SQL-answerable structure, an egress manifest, or local-only inference. Gemini brings Workspace data (Gmail/Calendar/Drive) and Gemini Notebook's source-grounded citations but no custom MCP in the consumer app and no memory export; it complements SecondBrain only through Gemini CLI on paid tiers. Copilot's strength is Graph-grounded enterprise retrieval under EDP; for a single home user it offers Notebooks capped at 300 files, memory tied to Bing/MSN activity, and MCP only via tenant admin connectors. Perplexity gives cited search plus connectors and a cheap Spaces layer (50 files) but trains by default and has no documented MCP client path. Le Chat is the most permissive (custom remote MCP and memory export on Free, on-prem deployment for Enterprise) but trains free-tier data by default. Grok and Apple are not second-brain candidates: Grok's memory is a beta without export beyond chat JSON; Siri AI is a Gemini-backed assistant whose personal-context store is Apple's, not the user's.

## Key question 2: Which assistants can connect as MCP clients to a self-hosted MCP server like SecondBrain, over which transports, with what auth, on desktop and mobile?

### Takeaway
Claude (web, Desktop, Cowork, mobile, Claude Code), ChatGPT/Codex (web via developer mode with contested plan gating; desktop app and CLI via local config), Gemini CLI (paid tiers), Le Chat (all plans) and Microsoft 365 Copilot (tenant-admin connectors only) can act as MCP clients; the decisive constraint for SecondBrain is that every vendor-cloud client (claude.ai, ChatGPT web, Le Chat, M365) requires the server to be reachable from the vendor's cloud over the public internet with OAuth or a fixed header credential, whereas only locally running clients (Claude Code, Claude Desktop extensions, Codex CLI/ChatGPT desktop app, Gemini CLI) can reach a WireGuard/Tailscale-only address or spawn a stdio process.

### Cited Findings

### Inferences
- A WireGuard/Tailscale-only SecondBrain is reachable by Claude Code, Claude Desktop (`.mcpb` or stdio launcher), Codex CLI / ChatGPT desktop app and Gemini CLI, because those clients run on the user's machine and can target a private IP or spawn a process; it is not reachable by claude.ai, Claude mobile, ChatGPT web, Le Chat or M365 Copilot, which connect from vendor clouds.
- The Cloudflare Tunnel + Cloudflare Access path makes SecondBrain reachable by vendor clouds, but Cloudflare Access sits in front of the MCP endpoint, so the OAuth discovery flows Claude and Codex perform (RFC 9728/8414, DCR) would have to pass through Access or SecondBrain would need to be the OAuth authorization server itself; the simplest vendor-cloud path is Claude's fixed request header (a service token) which Claude Code and Codex also support, while ChatGPT web's remote-only, OAuth-oriented developer mode is the hardest fit.
- Claude's "Research can invoke connector tools without further approval" and Gemini CLI's `trust` flag mean SecondBrain's own proposal/approval gate for writes is the only reliable control; client-side approval cannot be assumed.
- Mobile reach is cloud-only everywhere (Claude mobile uses synced remote connectors; no mobile client runs stdio), so any phone use of SecondBrain requires the public endpoint.

## Key question 3: What are the current data-use defaults for consumer accounts (training opt-in/out, retention), and what would a privacy-conscious user object to?

### Takeaway
As of 2026 every major consumer assistant trains on conversations by default with an opt-out (OpenAI "Improve the model for everyone", Anthropic "Help Improve our AI models" with 5-year retention when on, Google Keep Activity with human review and 18-month default retention, Perplexity "AI data retention", Grok "Allow your data to improve Grok", Mistral free tier under legitimate interest); opt-outs are forward-only; and only enterprise/API tiers offer contractual no-training, zero-data-retention or regional residency.

### Cited Findings
- OpenAI: "Improve the model for everyone" toggle; off means new conversations are not used for training; applies to Codex on personal plans — [OpenAI data controls (not fetched directly)](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt); business plans and API not trained on by default; EU residency for new Enterprise/Edu workspaces; EU API projects run with zero data retention — [OpenAI data residency (not fetched directly)](https://openai.com/index/introducing-data-residency-in-europe/); consumer and Team logs were under a court preservation order from May 13, 2025 until the going-forward duty was lifted Oct 9, 2025, with already-preserved logs remaining accessible — [CyberInsider](https://cyberinsider.com/us-court-orders-openai-to-preserve-all-chatgpt-logs-indefinitely/); [Mashable via Yahoo](https://www.yahoo.com/news/articles/judge-lifts-order-requiring-openai-151518813.html); Atlas browser memories were server-side summaries deleted within seven days — [Wikipedia: ChatGPT Atlas](https://en.wikipedia.org/wiki/ChatGPT_Atlas)
- Anthropic: Free/Pro/Max and Claude Code sessions train when the setting is on; opted-in data kept five years, else 30 days; existing users forced to choose by Oct 8, 2025 — [Anthropic](https://www.anthropic.com/news/updates-to-our-consumer-terms); deleted chats purged from back-end within 30 days; flagged content kept 2 years with scores 7 years — [Anthropic Privacy Center](https://privacy.claude.com/en/articles/10023548-how-long-do-you-store-my-data); memory is included in exports and follows chat retention; memory unavailable under HIPAA/custom retention — [Anthropic support](https://support.claude.com/en/articles/11817273-how-does-claude-s-memory-work); Enterprise offers custom retention and HIPAA-ready — [Claude pricing](https://claude.com/pricing)

- Perplexity: AI Data Retention on by default for Free/Pro/Max; forward-only opt-out; enterprise never trained; memory content may be used to improve models — [Perplexity help: Data Collection](https://intercom.help/perplexity-ai/en/articles/11564572-data-collection-at-perplexity); [Perplexity help: Memory](https://intercom.help/perplexity-ai/en/articles/10968016-memory)

### Inferences
- The objections a privacy-conscious single user would raise: (1) training-by-default on the very notes they would upload, with forward-only opt-outs that do not unwind past training runs; (2) multi-year retention tails (Anthropic 5 years when opted in, Google 3 years for human-reviewed chats, OpenAI's litigation hold) that outlive any "delete"; (3) human review of consumer chats (Google) and employee safety access (xAI); (4) memory stores that ingest sensitive data by default (Gemini) or require explicit toggles to exclude it (Claude); (5) court orders and legal holds applied to consumer tiers but not enterprise/ZDR tiers, which a home user cannot buy at single-seat scale.
- SecondBrain's per-turn egress cap and manifest, plus `local_only` enforced at the transport, address exactly the dimension none of these policies control: what leaves the user's machine per request, not what the vendor promises to do with it afterwards.

- Consumer Copilot training opt-out and retention were not found on the fetched page.

## Key question 4: Have there been notable incidents (memory leaks, prompt-injection via connectors/browsers, data exposure) in 2025–2026 relevant to trusting these with a personal corpus?

### Takeaway
Yes: 2025–2026 produced a steady series of zero-click or one-click prompt-injection exfiltration demonstrations against every major assistant's connector or browser surface (EchoLeak in M365 Copilot, AgentFlayer and ZombieAgent in ChatGPT connectors/apps, Gemini calendar-invite "promptware", Comet, Atlas/ChatGPT "Tainted Memories", CoSnitch in Copilot Personal, Rovo), plus policy-level exposures (OpenAI's litigation hold on consumer logs, Google human review); vendors patched specific exploits while researchers and Anthropic's own numbers (11.2% residual attack success in Claude for Chrome) show the class is unsolved.

### Cited Findings
- "The lethal trifecta" (June 16, 2025): private data + untrusted content + external communication; incidents cited include EchoLeak, GitHub's MCP server and GitLab Duo (2025) and earlier ChatGPT, Bard, NotebookLM, Copilot, Slack, Le Chat, Grok and Claude iOS cases; guardrail products with "95% detection" are "a failing grade in web security" — [Simon Willison](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/)
- EchoLeak (CVE-2025-32711): zero-click email injection into Microsoft 365 Copilot's RAG, bypassing XPIA classifiers, exfiltrating via a Teams open redirect; fixed — [Simon Willison, June 11, 2025](https://simonwillison.net/2025/Jun/11/echoleak/)
- AgentFlayer (Black Hat, Aug 2025): poisoned Google Drive document triggers ChatGPT to search Drive for secrets and leak them through image URLs; OpenAI's `url_safe` mitigation bypassed via Azure Blob URLs; connectors cover Google Drive, SharePoint, GitHub, Microsoft 365 — [Cyber Security News](https://cybersecuritynews.com/chatgpt-0-click-connectors-vulnerability)
- Gemini "Invitation Is All You Need" (Aug 6, 2025; reported Feb 2025): calendar-invite injection achieving smart-home control, location leak via URL open, Zoom launch, email-subject exfiltration and delayed tool invocation; Google published mitigations in June 2025 and called the research "theoretical" — [SafeBreach](https://www.safebreach.com/blog/invitation-is-all-you-need-hacking-gemini/)
- Comet (Aug 20, 2025): hidden Reddit-comment instructions made Comet read Gmail and leak an OTP enabling account takeover; incomplete first fix; Brave re-reported after disclosure — [Brave](https://brave.com/blog/comet-prompt-injection/)
- Claude for Chrome (Aug 25, 2025): 23.6% baseline attack success reduced to 11.2% with mitigations; browser-specific set 35.7% to 0% — [Anthropic](https://claude.com/blog/claude-for-chrome)
- ChatGPT "Tainted Memories" (Oct 27, 2025): CSRF injects persistent instructions into ChatGPT memory across devices and browsers; OpenAI could not reproduce — [The Register](https://www.theregister.com/2025/10/27/atlas_vulnerability_memory_injection/); Axios warned Atlas agent/memory features raise injection risk — [Axios (cited via Wikipedia)](https://www.axios.com/2025/10/28/atlas-chatgpt-openai-web-browser-security-privacy)
- ZombieAgent (Radware; Dec 2025): zero-click, persistence and worm-like propagation via ChatGPT apps; patched Dec 16, 2025 — [TechRadar (truncated fetch; from search extraction)](https://www.techradar.com/pro/security/this-zombieagent-zero-click-vulnerability-allows-for-silent-account-takeover-heres-what-we-know)
- 2026 (from search extractions, primaries not fetched): GrafanaGhost indirect injection in Grafana's assistant (Apr 2026) — [OECD AI Incidents](https://oecd.ai/en/incidents/2026-04-07-c3b4); Atlassian Rovo exfiltration paths (Varonis "RovoBlast" patched July 8, 2026; PromptArmor's content-borne path published Aug 5, 2026, unresolved at writing) — [Cloud Security Alliance](https://labs.cloudsecurityalliance.org/research/csa-research-note-atlassian-rovo-prompt-injection-data-exfil/); Varonis "CoSnitch" against Copilot Personal patched Aug 18, 2026, M365 Copilot Enterprise unaffected — [Hexnode](https://www.hexnode.com/blogs/cve-2026-24301-what-cosnitch-reveals-about-ai-assistant-data-exfiltration/); "SearchLeak" CVE-2026-42824 in M365 Copilot Search (CVSS 7.5) — [Aviatrix](https://aviatrix.ai/threat-research-center/copilot-searchleak-attack-cve-2026-42824); a Sept 2026 proof-of-concept exfiltrating connected Gmail data from ChatGPT across accounts — [Hexnode](https://www.hexnode.com/threat-watch/chatgpt-gmail-exfiltration-flaw-enterprise-ai-app-governance-and-xdr-lessons/); a cited "April 2026 MCP RCE class (CVE-2026-30623)" — [FutureAGI (secondary)](https://futureagi.com/blog/what-is-prompt-injection-defense-2026/)
- Vendor acknowledgements built into product docs: Anthropic warns custom connectors "may use prompt injection" and that Research invokes connector tools without approval — [Anthropic support](https://support.claude.com/en/articles/11175166-getting-started-with-custom-connectors-using-remote-mcp); Cowork launch guidance warned of prompt injection and accidental file deletion — [CloudThat (secondary)](https://www.cloudthat.com/resources/blog/claude-cowork-the-desktop-ai-agent-that-completes-work-not-just-conversations); Microsoft documents prompt-injection protections under EDP — [Microsoft Learn: EDP](https://learn.microsoft.com/en-us/copilot/microsoft-365/enterprise-data-protection)
- Data exposure by process rather than exploit: OpenAI consumer/Team logs preserved under court order from May 13, 2025 — [CyberInsider](https://cyberinsider.com/us-court-orders-openai-to-preserve-all-chatgpt-logs-indefinitely/); Google human review of consumer Gemini chats retained three years — [Gemini Apps Privacy Hub](https://support.google.com/gemini/answer/13594961); Windows Recall captured sensitive content despite filters in testing — [PCWorld](https://www.pcworld.com/article/2739587/windows-recall-is-too-risky-for-your-copilot-pc-turn-it-off-now.html)

### Inferences
- The attack pattern repeats across vendors because connectors give the model private data and untrusted content in one context with a URL/image egress; a personal corpus connected to any vendor assistant becomes exfiltrable the moment a poisoned document, invite or web page enters the same session.
- Memory is itself an injection target (Tainted Memories, ZombieAgent persistence): a vendor memory that silently rewrites can carry attacker instructions forward, which argues for SecondBrain's human-approved writes and revisioned documents.
- SecondBrain's per-turn egress cap and manifest are a structural answer to the "external communication" leg; its read-only MCP tools plus proposal-based writes answer the "consequential action" leg; but it inherits the "untrusted content" leg from whatever enters its inbox and should treat ingested files as hostile.

### Gaps
- Radware's ShadowLeak (ChatGPT Deep Research + Gmail, Sept 2025) and ZombieAgent primary posts, Wired's AgentFlayer report and Aim Labs' EchoLeak page were not fetchable; a cross-user memory or chat leak in 2025–2026 (as opposed to injection) was not found, and the Aug 2025 reports of shared ChatGPT/Grok chats being indexed by search engines could not be verified before the search budget ran out.
